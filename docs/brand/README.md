# Studio brand

## The mark

**Lattice Ascent** (`assets/logo.svg`, chosen by the owner on 2026-10-20 from three concepts).

A 4 × 4 grid of rounded squares that grow and twist toward one bright cell. Structure that scales (engineering at scale) rising toward a single point of focus (one product). It is abstract and original: it is built from the idea, not from any existing mark.

| Property | Value |
|----------|-------|
| Tile | `#15131F`, corner radius 28 of 128 |
| Purples (small to large cells) | `#2A2250`, `#3A2E78`, `#4B35A8`, `#6E56CF`, `#8470E0` |
| Accent | `#F5B544`, the single amber cell (the only warm colour in the product) |
| Cell twist | 0° to 45°, rising with size |
| Clear space | At least a quarter of the mark's width on every side |

Do not recolour the amber cell, stretch the mark, add effects or place it on a busy background. At 16 px the fine cells blur; the dark tile, purple grid and amber top-right cell remain, which is what identifies it.
