## Checked and found sound (reviewer)

Privacy and CSP (only `css/site.css`, `scripts/smoke.js` and a test file changed; no new storage, cookie, request, host or script); reduced-motion block and no scripted smooth scroll; focus order at 375 px matches the visual order and there is no positive tabindex; cascade of the other phone rules; the negative margin on `a.read-title` does not overlap neighbours; the hero's radial gradient does not reach text; the viewport does not block zoom; the harness changes cannot hang or leak between cases; widths 320 and 640 px are a fair stand-in for Chrome page zoom.

## Not checked

A real iPhone or Safari (safe-area, text zoom), Firefox text-only zoom, screen readers (VoiceOver, NVDA), real pinch zoom, Windows High Contrast.
